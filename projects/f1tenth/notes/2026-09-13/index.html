v0 MPC on Isaac Sim

I've been working on this project on and off since mid 2025. This initial post will cover everything I've done so far, which includes the ROS2 scaffolding, Isaac Sim setup, and the initial MPC implementation. My goal is to continue building on this foundation over time as I learn more about automomy, controls, ML techniques, and more, eventually moving this project from simulation to a real RC car. The vehicle model I'm using is based on the Traxxas Slash RC car.

To get to this point, I setup the ROS2 workspace and traxxas slash model in Isaac Sim. From there, I used the Isaac Sim guides to set up a teleop node which I used to generate a centerline path for the car to eventually follow, serving as the reference trajectory for the MPC controller.

The MPC controller is implemented in a ROS2 node
