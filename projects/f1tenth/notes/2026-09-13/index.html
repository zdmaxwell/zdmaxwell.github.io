v0 MPC on Isaac Sim

I've been working on this project on and off since mid 2025. This initial post will cover everything I've done so far, which includes the ROS2 scaffolding, Isaac Sim setup, and the initial MPC implementation. My goal is to continue building on this foundation over time as I learn more about autonomy, controls, ML techniques, and more, eventually moving this project from simulation to a real RC car. The vehicle model I'm using is based on the Traxxas Slash RC car.

To get to this point, I setup the ROS2 workspace and Traxxas Slash model in Isaac Sim. From there, I used the Isaac Sim guides to set up a teleop node which I used to generate a centerline path for the car to eventually follow, serving as the reference trajectory for the MPC controller.

Isaac Sim publishes the state of the car (position, velocity, heading) on the /odom topic. The odom callback has four phases:

  1. Getting the current state
  2. Finding the local waypoints
  3. Solving for the optimal control inputs
  4. Publishing the result to the car

From the current state, the node finds the closest centerline point, then takes forward samples from the centerline points and translates them into the car's frame. So at this point, we have a set of waypoints in the car's frame (i.e. up to 30, set from path.max_waypoints). Those local waypoints are then fit with a cubic polynomial y = c₀ + c₁x + c₂x² + c₃x³; that polynomial is the reference trajectory: in other words, evaluated at any distance ahead of the car, it gives the desired lateral position and heading as seen below.
